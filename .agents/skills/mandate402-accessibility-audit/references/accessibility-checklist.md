# Accessibility Checklist

Operator-console essentials:

- visible focus states
- logical tab order
- clear accessible names for icon buttons
- modal focus trap and focus return
- status text for blocked, unknown, degraded, and queued states
- semantic headings in page order
- form errors connected to inputs
- tables with headers or accessible card transforms
- no color-only status meaning
- sufficient contrast for badges, CTAs, and warnings

Destructive actions:

- clear action name
- confirmation step
- cancellable path
- post-action success or failure state
